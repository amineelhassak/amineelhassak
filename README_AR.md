### 🎓 الخلفية الأكاديمية
- **إجازة في SMI** - الرياضيات والمعلوميات
  - **الجامعة**: جامعة سيدي محمد بن عبد الله، فاس
  - **التخصص**: الرياضيات التطبيقية، علوم الحاسوب، وتكنولوجيا المعلومات
  - **المواد الأساسية**: الرياضيات المتقدمة، البرمجة، الخوارزميات، أنظمة قواعد البيانات، هندسة البرمجيات

- **مدرسة 1337** - جزء من شبكة 42
  - **المؤسسة**: 1337 (شبكة 42)
  - **البرنامج**: التعلم من نظير إلى نظير في علوم الحاسوب
  - **التخصص**: هندسة البرمجيات، إدارة الأنظمة، وتطوير الخوارزميات
  - **المشاريع الأساسية**: 
    - **Born2beroot** (125/125) - إدارة أنظمة Linux والتشغيل الافتراضي
    - **CPP Modules 00-09** (100/100 لكل منها) - أساسيات برمجة C++
    - **Libft** (125/125) - تنفيذ مكتبة C مخصصة
    - **NetPractice** (100/100) - تكوين الشبكات والبروتوكولات
    - **Philosophers** (125/125) - البرمجة متعددة الخيوط والمزامنة
    - **cub3d** (125/125) - محرك رسومات ثلاثي الأبعاد باستخدام raycasting
    - **ft_printf** (100/100) - تنفيذ printf مخصص
    - **get_next_line** (125/125) - قراءة الملفات وإدارة الذاكرة
    - **minishell** (120/125) - تنفيذ shell مع تحليل الأوامر
    - **minitalk** (125/125) - التواصل بين العمليات باستخدام الإشارات
    - **push_swap** (125/125) - تحسين الخوارزميات والفرز
    - **so_long** (125/125) - تطوير ألعاب ثنائية الأبعاد مع خوارزميات البحث عن المسار
  - **طريقة التعلم**: التعلم القائم على المشاريع مع التقييم من الأقران

### 🚀 ما أفعله

- **هندسة الأنظمة** - تصميم أنظمة برمجية قابلة للتطوير والصيانة
- **تصميم قواعد البيانات** - إنشاء نماذج بيانات قوية وتحسين الاستعلامات
